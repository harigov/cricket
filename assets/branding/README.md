# Willow Cricket identity artwork

This folder contains original fictional branding created for the game. It does
not reproduce national cricket-board or commercial sponsor marks.

## Team marks

Each 512 x 512 crest combines the team's in-game colors with a distinctive
symbol that remains readable on uniform badges and stadium boards:

- IND — cricket-ball sun and crossed bats
- AUS — angular kangaroo and Southern Cross cricket balls
- ENG — crowned batting lion and cricket-ball rose
- PAK — crescent, star, and fast-delivery cricket ball
- RSA — springbok and cricket-seam protea
- NZL — silver fern and black cricket ball
- WIS — frigatebird, palms, cricket ball, and wave
- LKA — golden batting lion and island wave
- BGD — Bengal tiger, cricket-ball sun, and water lilies
- AFG — snow leopard, mountain peak, and cricket-ball sunrise

## Stadium ribbon

`stadium/sponsor-ribbon.png` is a 2048 x 368 fictional broadcast ribbon with
four game-original brands: WILLOW, PULSE, NOVA, and STRIKE.

The raster artwork is embedded by `RenderPlugin`, so the compiled game remains
self-contained when launched outside the repository.
